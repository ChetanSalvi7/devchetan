## 🌐 How to Deploy on GitHub Pages

1. **Push the files to GitHub**:
   ```bash
   git add .
   git commit -m "feat: complete developer website with anime wallpaper and child safety policy"
   git push origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/ChetanSalvi7/devchetan`
   - Click on **Settings** (top tab).
   - In the left sidebar, click on **Pages**.
   - Under **Build and deployment** > **Branch**:
     - Select branch: `main`
     - Select folder: `/ (root)`
     - Click **Save**.

3. **Your Live Website URL**:
   Your site will be live within 1–2 minutes at:
   - **Homepage:** `https://chetansalvi7.github.io/devchetan/`
   - **Anime Wallpaper Page:** `https://chetansalvi7.github.io/devchetan/anime_wallpaper.html`
   - **Child Safety Policy:** `https://chetansalvi7.github.io/devchetan/child_safty.html`
   - **Privacy Policy:** `https://chetansalvi7.github.io/devchetan/privacy_policy.html`

Use these URLs directly inside your Google Play Console app setup for policy verification!
